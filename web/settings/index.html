导入的壁纸放在 …，单文件 HTML 建议把 CSS/JS 内联，文件夹需要根目录下有 index.html。

渲染

帧率上限 不限 = 跟随显示器刷新率；也可以自己填 1–240
流动速度1.0×
画面强度1.0
元素密度 粒子 / 光斑 / 字符列的数量
1.0

三个参数对所有壁纸生效，改动立即应用并写入 config.json。

省电

全屏应用时暂停 检测到全屏游戏/视频时停止渲染
锁屏时暂停 息屏 / 锁屏后释放 GPU
窗口最大化时暂停 前台有最大化窗口盖住桌面时停止渲染
打开设置面板时暂停 默认关闭，仅降低帧率

互动

壁纸跟随鼠标 把光标位置推给壁纸页面，涟漪 / 追光 / 群星要用它

启动

开机自启 登录时自动启动，写入 HKCU\Software\Microsoft\Windows\CurrentVersion\Run
启用开发者工具 下次创建视图时生效

运行信息

实时帧率 壁纸页面每 2 秒上报一次；60 表示满帧，掉到 50 以下说明真的在丢帧
